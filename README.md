### ВОПРОС 1. Случайные события и соотношения между ними

#### § 1. Введение в теорию вероятностей

- **Закономерности детерминистические (определённые)** — результат эксперимента однозначно определяется условиями.
- **Закономерности статистические (вероятностные)** — изучаются методами теории вероятностей и математической статистики.
- **Цель теории вероятностей** — осуществление прогноза в области случайных явлений, влияние на ход этих явлений, контроль их, ограничение сферы действия случайности.
- **Определение 1.** Теория вероятностей — это математическая наука, изучающая математические модели случайных экспериментов.

Любой эксперимент S характеризуется двумя факторами:
1. комплекс условий U, при котором S происходит;
2. результаты эксперимента — некоторые события A₁, A₂, …, наступление или ненаступление которых регистрируется в ходе эксперимента.

**Определение 2.** Эксперимент S называется **детерминированным**, если комплекс условий U однозначно определяет результат эксперимента.

**Определение 3.** Событие A, которое при данном комплексе условий U **неизбежно наступает**, называется **достоверным событием**. Событие B, которое **неизбежно не наступает**, называется **невозможным событием**.

**Определение 4.** **Случайным экспериментом** называется недетерминированный эксперимент S, для которого выполняются два свойства:
1. эксперимент допускает массовое, n-кратное (n сколь угодно большое) повторение;
2. выполняется **свойство статистической устойчивости**.

**Свойство статистической устойчивости:** пусть эксперимент S осуществлён n-кратно. Обозначим:
- mₙ(A) — число наступлений события A в серии из n экспериментов;
- νₙ(A) = mₙ(A)/n — относительная частота наступления события A.

Свойство состоит в том, что для любого события A при возрастании n последовательность относительных частот сходится к некоторому пределу:
> νₙ(A) → P(A), где P(A) ∈ [0, 1] — **вероятность** случайного события A.

#### § 2. Случайные события и соотношения между ними

**Определение 1.** События, составляющие множество {ω} простейших исходов случайного эксперимента S, называются **элементарными событиями (ЭС)**, если:
1. все элементарные события различны;
2. наступление одного исхода исключает наступление всех остальных;
3. в ходе эксперимента одно из элементарных событий неизбежно наступает.

**Множество Ω = {ω}**, составленное из всех элементарных событий, называется **пространством элементарных событий (ПЭС)**.

**Определение 2.** Объединение A некоторых элементарных событий из Ω называется **случайным событием**. Случайное событие — это подмножество ПЭС: A ⊆ Ω. При этом:
- A = Ω — **достоверное событие**;
- A = ∅ — **невозможное событие**.

**Соотношения между случайными событиями** (A, B, C ⊆ Ω):

| Обозначение | Название | Пояснение |
|---|---|---|
| B ⊂ C | Событие B **влечёт** C | C наступает всякий раз, когда наступает B |
| B = C | События **эквивалентны** | B наступает тогда и только тогда, когда наступает C |
| A = B̄ | A — **противоположное** B | A наступает тогда и только тогда, когда не наступает B |
| A = B ∩ C | A — **произведение** B и C | A наступает тогда и только тогда, когда B и C наступают вместе |
| B ∩ C = ∅ | B и C **несовместны** | Совместное наступление B и C невозможно |
| A = B ∪ C | A — **сумма** B и C | A наступает тогда и только тогда, когда наступает B или C, или оба вместе |
| A = B \ C = B ∩ C̄ | A — **разность** B минус C | A наступает тогда и только тогда, когда наступает B и не наступает C |
| A = BΔC | A — **симметрическая разность** B и C | A наступает тогда и только тогда, когда наступает либо B, либо C (не одновременно) |

**Правило де Моргана.** Пусть событие A есть результат применения к событиям B, C, D, … действий ∩, ∪. Тогда, чтобы получить Ā, достаточно все события поменять на противоположные, а действия поменять по схеме: ∩ → ∪, ∪ → ∩.

### ВОПРОС 2. Понятие вероятности. Простейшие вероятностные модели

Рассматриваются три типа простейших вероятностных моделей: **классическая, дискретная, геометрическая**.

#### 1. Классическая вероятностная модель

**Определение 1.** Классическая вероятностная модель — это математическая модель простейшего эксперимента, определяемая четырьмя аксиомами:
- **А1.** Пространство ЭС конечно: Ω = {ω₁, …, ωₙ}, N < ∞;
- **А2.** Каждому случайному событию A ⊆ Ω сопоставлено число P(A) ∈ [0, 1], P(∅) = 0, P(Ω) = 1;
- **А3 (конечная аддитивность).** Для любых несовместных A, B: P(A ∪ B) = P(A) + P(B);
- **А4 (равновероятность).** Все N элементарных событий равновероятны: P(ω₁) = … = P(ωₙ) = p ∈ (0, 1).

**Теорема 1.** Для классической модели вероятность p = 1/N, а вероятность произвольного события:
> **P(A) = |A| / |Ω| = M / N**,
> где N = |Ω| — число всех ЭС, M = |A| — число благоприятствующих ЭС.

**Пример (гипергеометрическое распределение).** В сосуде K шаров, среди которых k красных и (K − k) белых. Извлекаем L шаров. Вероятность события Aₗ = {среди L извлечённых l красных}:
> Pₗ = CₖˡC_{K-k}^{L-l} / Cₖᴸ, l = 0, 1, …, min{k, L}.

#### 2. Дискретная вероятностная модель

**Определение 3.** Определяется аксиомами:
- **А1′.** Ω = {ω₁, ω₂, …} — дискретное (конечное либо счётное) множество;
- **А2.** Без изменений;
- **А3′ (счётная аддитивность).** Для любой последовательности попарно несовместных событий: P(∪Aᵢ) = ΣP(Aᵢ).

**Теорема 2.** P(A) = Σₖ: ωₖ∈A pₖ, где pₖ = P(ωₖ) — k-я элементарная вероятность.

**Следствие.** Условие нормировки: Σpₖ = 1.

#### 3. Геометрическая вероятностная модель

Обобщение классической модели на случай, когда Ω — ограниченное подмножество Rᵐ (m = 1, 2, …). Все элементарные события равновозможны.

**Определение 5.** Вероятность:
> **P(A) = μ(A) / μ(Ω)**,
> где μ — мера Лебега (длина, площадь, объём и т.д.).

### ВОПРОС 3. Алгебра, σ-алгебра. Измеримое пространство. Аксиомы теории вероятностей

#### § 4. Алгебра и σ-алгебра

**Определение 1.** Система F подмножеств из Ω называется **алгеброй** случайных событий, если:
1. Ω ∈ F;
2. если A ∈ F, то Ā ∈ F;
3. если A, B ∈ F, то A ∪ B ∈ F.

**Следствие:** также ∅ ∈ F и если A, B ∈ F, то A ∩ B ∈ F. Алгебра замкнута относительно конечного числа операций ∩, ∪, \.

**Определение 2.** Алгебра F называется **σ-алгеброй**, если свойства 3 и 5 выполняются для счётного множества событий:
> ∀ A₁, A₂, … ∈ F ⟹ ∪Aᵢ ∈ F, ∩Aᵢ ∈ F.

σ-алгебра замкнута относительно **счётного** множества операций.

**Определение 3.** **Измеримым пространством** называется пара (Ω, F), где Ω — ПЭС, F — алгебра или σ-алгебра.

**Борелевская σ-алгебра B = B(R).** Строится на числовой прямой на основе базовой системы F₀ = {∅, Aₓ = (−∞, x) : x ∈ R}. Элементы B называются **борелевскими множествами**. Свойства:
- Одноточечные множества {z} борелевские;
- Числовые промежутки (a, b), [a, b), (a, b], [a, b] борелевские;
- Множество рациональных чисел Q борелевское.

#### § 5. Аксиомы теории вероятностей

**Определение 1 (А.Н. Колмогоров).** Числовая функция P = P(A) : F → R называется **вероятностной мерой**, а число P(A) — **вероятностью** случайного события A, если выполняются аксиомы:
- **А1.** F есть алгебра подмножеств из Ω;
- **А2.** 0 ≤ P(A) ≤ 1 ∀ A ∈ F;
- **А3 (нормировки).** P(Ω) = 1;
- **А4 (конечная аддитивность).** Для несовместных A, B ∈ F: P(A ∪ B) = P(A) + P(B).

При бесконечном Ω аксиомы обобщаются:
- **А1′.** F — σ-алгебра;
- **А4′ (счётная аддитивность).** Для попарно несовместных Aᵢ: P(∪Aᵢ) = ΣP(Aᵢ).

**Определение 2.** **Вероятностным пространством** называется тройка (Ω, F, P), где Ω — ПЭС, F — σ-алгебра, P — вероятностная мера.

**А5 (аксиома непрерывности).** Для любой монотонно убывающей последовательности Aₙ ↓:
> lim P(Aₙ) = P(lim Aₙ) = P(∩Aₙ).

### ВОПРОС 4. Свойства вероятности (вероятностной меры)

Пусть (Ω, F, P) — вероятностное пространство.

- **С1.** P(Ā) = 1 − P(A).
- **С2.** P(∅) = 0.
- **С3 (монотонность).** A ⊂ B ⟹ P(A) ≤ P(B). Следствие: P(B \ A) = P(B) − P(A).
- **С4 (формула сложения).** **P(A ∪ B) = P(A) + P(B) − P(A ∩ B).**
- **С4′ (обобщённая формула сложения):**
  > P(∪ᵢ₌₁ᴺ Aᵢ) = ΣP(Aᵢ) − ΣΣP(Aᵢ ∩ Aⱼ) + ΣΣΣ P(Aᵢ ∩ Aⱼ ∩ Aₖ) − … + (−1)^{N−1} P(∩Aᵢ).
- **С5.** P(∪Aᵢ) ≤ ΣP(Aᵢ) (субаддитивность).
- **С6 (эквивалент А5).** Для монотонно возрастающей последовательности Aₙ ↑: lim P(Aₙ) = P(∪Aₙ).

### ВОПРОС 5. Условная вероятность. Формула полной вероятности. Формула Байеса

#### § 7. Условная вероятность

**Определение 1.** Пусть P(B) > 0. **Условной вероятностью** события A при условии B называется:
> **P(A | B) = P(A ∩ B) / P(B).**

**Свойства условной вероятности:**
- **С1.** При фиксированном B функция Pₐ(A) := P(A | B) удовлетворяет всем аксиомам теории вероятностей.
- **С2.** P(Ā | B) = 1 − P(A | B); P(A ∪ B | C) = P(A | C) + P(B | C) − P(A ∩ B | C).
- **С3 (формула умножения).** Если P(B) > 0, то: P(A ∩ B) = P(A | B) P(B).
- **Симметричная формула умножения:** P(A ∩ B) = P(A | B) P(B) = P(B | A) P(A).
- **С4 (обобщённая формула умножения):** P(∩ᵢ₌₁ᴺ Aᵢ) = P(A₁) · Πᵢ₌₁ᴺ⁻¹ P(Aᵢ₊₁ | ∩ⱼ₌₁ⁱ Aⱼ).

**Определение 2.** Система событий H₁, H₂, …, Hₙ называется **полной системой** (полной группой гипотез), если:
1. ∪Hᵢ = Ω;
2. Hᵢ ∩ Hⱼ = ∅ при i ≠ j;
3. P(Hᵢ) > 0.

**Теорема 1 (формула полной вероятности):**
> **P(A) = Σᵢ₌₁ᴺ P(A | Hᵢ) P(Hᵢ).**

**Теорема 2 (формула Байеса).** Пусть P(A) > 0:
> **P(Hᵢ | A) = P(A | Hᵢ) P(Hᵢ) / Σⱼ P(A | Hⱼ) P(Hⱼ).**

- P(Hᵢ) — **априорная вероятность** (до опыта);
- P(Hᵢ | A) — **апостериорная вероятность** (после опыта).

### ВОПРОС 6. Независимые случайные события и их свойства

#### § 8. Независимые случайные события

**Определение 1.** События A, B ∈ F называются **независимыми**, если:
> **P(A ∩ B) = P(A) P(B).**

В противном случае A и B **зависимы**.

**Свойства:**
- **С1 (критерий независимости).** Если P(B) > 0, то A и B независимы ⟺ P(A | B) = P(A). Содержательный смысл: наступление одного события **не влияет** на вероятность наступления другого.
- **С2.** Свойство независимости переносится на противоположные события: если A и B независимы, то Ā и B̄ независимы.
- **С3.** Если A и C независимы, B и C независимы, A и B несовместны, то A ∪ B и C независимы.

**Определение 2.** События A₁, …, Aₙ называются **независимыми в совокупности**, если для любого m ∈ {2, …, n} и любых m индексов:
> P(∩Aᵢⱼ) = ΠP(Aᵢⱼ).

Если выполняется лишь для m = 2 — события **попарно независимы**.

- **С4.** Из независимости в совокупности следует попарная независимость. Обратное **неверно** (контрпример Бернштейна).
- **С5 (обобщённая формула для независимых в совокупности):**
  > P(∪ᵢ₌₁ᴺ Aᵢ) = 1 − Πᵢ₌₁ᴺ (1 − P(Aᵢ)).

### ВОПРОС 7. Понятие случайной величины. Функция распределения и её свойства

#### § 1. Понятие случайной величины

**Определение 1.** Функция ξ : Ω → R называется **случайной величиной (СВ)**, если для любого борелевского множества B ∈ B(R) множество ξ⁻¹(B) = {ω ∈ Ω : ξ(ω) ∈ B} является случайным событием, т.е. принадлежит σ-алгебре F.

**Определение 2 (эквивалентное).** ξ(ω) : Ω → R — СВ, если ∀ x ∈ R прообраз Aₓ = (−∞, x) является случайным событием: ξ⁻¹(Aₓ) ∈ F.

**Определение 3.** **Распределением** СВ ξ называется вероятностная мера μ(B) = P{ξ ∈ B} на борелевских подмножествах R.

**Определение 4.** **Функцией распределения** СВ ξ называется функция Fξ : R → [0, 1]:
> **Fξ(x) = P{ξ < x}** = P{ω : ξ(ω) < x}.

**Теорема 1.** Для ∀ B ∈ B распределение P{ξ ∈ B} однозначно выражается через Fξ(·). В частности:
> - P{ξ ≥ x} = 1 − Fξ(x);
> - P{x₁ ≤ ξ < x₂} = Fξ(x₂) − Fξ(x₁);
> - P{ξ = x} = Fξ(x + 0) − Fξ(x).

**Теорема 2 (свойства функции распределения):**
- **С1.** 0 ≤ Fξ(x) ≤ 1;
- **С2. Неубывание:** x₁ < x₂ ⟹ Fξ(x₁) ≤ Fξ(x₂);
- **С3.** lim_{x→−∞} Fξ(x) = 0 и lim_{x→+∞} Fξ(x) = 1;
- **С4. Непрерывность слева:** Fξ(x − 0) = Fξ(x) ∀ x ∈ R.

**Теорема 3 (обратная).** Свойства С1–С4 **полностью характеризуют** класс всевозможных функций распределения.

### ВОПРОС 8. Дискретные функции распределения. Основные законы дискретного распределения

**Определение 1.** СВ ξ имеет **дискретное распределение**, если множество X её значений дискретно: X = {x₁, x₂, …, xₘ}, M ≤ ∞, с элементарными вероятностями pᵢ = P{ξ = xᵢ} > 0.

Дискретное распределение задаётся таблицей значений xᵢ и вероятностей pᵢ. **Условие нормировки:** Σpᵢ = 1.

Функция распределения дискретной СВ:
> **Fξ(x) = Σᵢ: xᵢ < x pᵢ** — ступенчатая функция.

**Основные законы дискретного распределения:**

1. **Закон Бернулли** Bi(1, p): X = {0, 1}, pₓ = pˣ(1−p)^{1−x}.

2. **Биномиальное распределение** Bi(N, p): X = {0, 1, …, N}, pₓ = Cₙˣpˣqᴺ⁻ˣ.
   - Возникает как сумма N независимых СВ Бернулли; ξ = ξ(ω) — случайное число успехов в N испытаниях.

3. **Дискретный равномерный закон** DR(X): X = {x₁, …, xₘ}, pₓ = 1/M.

4. **Гипергеометрическое распределение** H(K, k, L): pₓ = CₖˣC_{K-k}^{L-x} / Cₖᴸ.
   - K шаров в урне, k красных, L извлекаем; ξ — число извлечённых красных.

5. **Геометрическое распределение** G(p): X = {0, 1, 2, …}, pₓ = (1−p)ˣp.
   - ξ — число проверок до первого «успеха».

6. **Закон Пуассона** Π(λ), λ > 0: X = {0, 1, 2, …}, **pₓ = λˣe⁻λ / x!**
   - ξ — число событий (посетителей, звонков…) за единицу времени; λ — среднее число.

### ВОПРОС 9. Плотность распределения вероятностей. Основные абсолютно непрерывные законы

**Определение 2.** Функция распределения Fξ(·) называется **абсолютно непрерывной**, если существует неотрицательная интегрируемая функция pξ(x) ≥ 0 такая, что:
> **Fξ(x) = ∫_{−∞}^{x} pξ(y) dy.**

Функция pξ(x) называется **плотностью распределения вероятностей**.

**Свойства плотности:**
- **С1.** pξ(x) ≥ 0;
- **С2 (нормировка).** ∫_{−∞}^{+∞} pξ(y) dy = 1;
- **С3.** P{a ≤ ξ < b} = ∫ₐᵇ pξ(y) dy (геометрически — площадь под кривой);
- **С4.** P{ξ = x} = 0 (вероятность точки равна нулю для непрерывной СВ);
- **С5.** В точке непрерывности: pξ(x) = F′ξ(x).

**Основные абсолютно непрерывные законы:**

1. **Равномерный закон** R[a, b], a < b:
   - pξ(x) = 1/(b−a) при x ∈ [a, b], иначе 0;
   - Стандартный: a = 0, b = 1.

2. **Нормальный (гауссовский) закон** N(a, D), a ∈ R, D > 0:
   > **pξ(x) = (1/√(2πD)) · exp{−(x−a)²/(2D)}**
   - График — нормальная кривая Гаусса, симметричная относительно x = a;
   - Стандартный нормальный закон N(0, 1): φ(x) = (1/√(2π)) · exp{−x²/2};
   - Стандартная нормальная ФР: Φ(x) = (1/√(2π)) ∫_{−∞}^{x} e^{−t²/2} dt;
   - Свойство: Φ(−x) = 1 − Φ(x); связь с общим: Fξ(x) = Φ((x−a)/√D).

3. **Показательный (экспоненциальный) закон** E(λ), λ > 0:
   > pξ(x) = λe^{−λx} при x ≥ 0; Fξ(x) = 1 − e^{−λx} при x ≥ 0.

### ВОПРОС 10. Многомерная случайная величина и случайный n-вектор

**Определение 1.** Упорядоченный набор n СВ ξ₁, …, ξₙ, определённых на одном (Ω, F, P), называется **n-мерной СВ** или **случайным n-вектором** ξ = (ξ₁, …, ξₙ)ᵀ.

**Определение 2.** **n-мерная функция распределения** (совместная ФР):
> **Fξ(x) = P{ξ₁ < x₁, …, ξₙ < xₙ}**, x = (xᵢ) ∈ Rⁿ.

**Свойства:**
- **С1.** Fξ(x) ∈ [0, 1];
- **С2.** Неубывание по каждому аргументу;
- **С3.** Предельные соотношения: Fξ(x)|_{xᵢ=−∞} = 0; Fξ(x)|_{всех xᵢ=+∞} = 1;
- **С4.** Непрерывна слева по совокупности аргументов;
- **С5 (согласованность).** Fξ(x)|_{xᵢ=+∞} = F_{ξ₁,…,ξᵢ₋₁,ξᵢ₊₁,…,ξₙ}(x₁,…,xᵢ₋₁,xᵢ₊₁,…,xₙ).

**k-мерная маргинальная (частная) ФР** — ФР подвектора ξ′, получается устремлением (n−k) остальных переменных к +∞.

**Определение 4.** n-мерная ФР **абсолютно непрерывна**, если существует **совместная плотность** pξ(y) такая, что:
> Fξ(x) = ∫_{−∞}^{x₁} … ∫_{−∞}^{xₙ} pξ(y₁,…,yₙ) dy₁…dyₙ.

**Свойства n-мерной плотности:** аналогичны одномерному случаю + свойство согласованности (маргинальная плотность = интеграл по остальным переменным).

**Основные n-мерные законы:**
1. **n-мерный нормальный закон** Nₙ(a, B), a ∈ Rⁿ, B — симметрич. положительно определённая матрица:
   > pξ(x) = (2π)^{−n/2} (det B)^{−1/2} exp{−½(x−a)ᵀB⁻¹(x−a)}.
   - Маргинальные распределения тоже нормальны: L{ξᵢ} = N(aᵢ, bᵢᵢ).

2. **Полиномиальное распределение** Pol(N, n, p₁,…,pₙ): возникает при N испытаниях с n исходами. При n = 2 — биномиальное.

---

### ВОПРОС 11. Условная функция распределения, условная плотность и их свойства

**Определение 1.** При C ∈ F, P(C) > 0 **условная ФР** случайного вектора ξ при условии C:
> Fξ(x | C) = P{ξ ∈ Aₓ | C} = P({ξ ∈ Aₓ} ∩ C) / P(C).

**Определение 2.** Если η = y — дискретный вектор с P{η = y} > 0:
> Fξ|η(x | y) = P{ξ ∈ Aₓ | η = y}.

**Определение 3.** Если (ξ, η)ᵀ имеет абсолютно непрерывное распределение с совместной плотностью pξ,η(x, y) и pη(y) > 0:
> Fξ|η(x | y) = lim_{ε→0} P{ξ ∈ Aₓ | η ∈ Cᵧ(ε)} = ∫_{Aₓ} pξ|η(u | y) du,
> где **pξ|η(x | y) = pξ,η(x, y) / pη(y)** — **условная плотность**.

**Свойства условной плотности:**
- **С1.** pξ|η(x | y) ≥ 0;
- **С2 (нормировка).** ∫pξ|η(x | y) dx = 1 ∀ y;
- **С3.** P{ξ ∈ B | η = y} = ∫_B pξ|η(x | y) dx;
- **С4.** pξ|η(x | y) = ∂ⁿFξ|η(x | y) / ∂x₁…∂xₙ;
- **С5 (формула умножения плотностей).** pξ,η(x, y) = pξ|η(x | y) pη(y) = pη|ξ(y | x) pξ(x);
- **С6 (безусловная плотность).** pξ(x) = ∫ pξ|η(x | y) pη(y) dy;
- **С7 (формула Байеса для плотностей).** pη|ξ(y | x) = pξ|η(x | y) pη(y) / ∫pξ|η(x | y) pη(y) dy.

### ВОПРОС 12. Независимость случайных величин. Критерии независимости

**Определение 1.** СВ ξ₁, …, ξₙ называются **независимыми в совокупности**, если для любых борелевских B₁, …, Bₙ:
> **P{ξ₁ ∈ B₁, …, ξₙ ∈ Bₙ} = Πᵢ P{ξᵢ ∈ Bᵢ}.**

**Свойства:**
- **С1.** Независимость сохраняется при борелевских функциональных преобразованиях.
- **С2 (общий критерий).** ξ₁, …, ξₙ независимы ⟺ Fξ₁,…,ξₙ(x₁,…,xₙ) = Πᵢ Fξᵢ(xᵢ).
- **С3 (для непрерывных СВ).** Независимы ⟺ pξ₁,…,ξₙ(x₁,…,xₙ) = Πᵢ pξᵢ(xᵢ).
- **Следствие 1.** ξ и η независимы ⟺ pξ|η(x | y) = pξ(x).
- **Следствие 3 (для гауссовских).** ξ₁,…,ξₙ ~ Nₙ(a, B) независимы ⟺ матрица B **диагональная**.

### ВОПРОС 13. Функциональные преобразования случайных величин. Формула свёртки

**Постановка задачи.** Дан случайный вектор ξ ∈ Rⁿ с ФР Fξ и функциональное преобразование η = f(ξ) : Rⁿ → Rᵐ. Требуется найти закон распределения L{η}.

**Случай ФП-1 (невырожденное преобразование, m = n, det(Df) ≠ 0):**

**Теорема 1.** Если pξ(x) непрерывна и f — невырожденное дифференцируемое преобразование, то плотность η = f(ξ):
> **pη(y) = pξ(f⁻¹(y)) · |Df⁻¹(y)/Dy|.**

**Следствие 1 (линейное преобразование).** η = aξ + b, b ≠ 0:
> pη(y) = (1/|b|) pξ((y−a)/b).

**Следствие 2 (несколько обратных функций).** Если уравнение f(x) = y имеет K решений f⁻¹₁(y), …, f⁻¹ₖ(y):
> pη(y) = Σₖ pξ(f⁻¹ₖ(y)) · |Df⁻¹ₖ(y)/Dy|.

**Теорема 2 (формула свёртки).** Пусть ξ₁, ξ₂ — **независимые** СВ с плотностями pξ₁ и pξ₂. Плотность суммы η = ξ₁ + ξ₂:
> **pη(y) = ∫_{−∞}^{+∞} pξ₁(y − z) pξ₂(z) dz.**

### ВОПРОС 14. Математическое ожидание случайных величин. Простейшие свойства

**Определение 1.** **Математическим ожиданием (средним значением)** дискретной СВ ξ называется:
> **m = E{ξ} = Σᵢ aᵢ pᵢ** (сходимость ряда абсолютная).

**Определение 2.** Для непрерывной СВ с плотностью pξ(x):
> **m = E{ξ} = ∫_{−∞}^{+∞} x pξ(x) dx** (абсолютная сходимость: ∫|x| pξ(x) dx < ∞).

**Замечание.** В общем случае m = ∫_Ω ξ(ω) P(dω) = ∫_{−∞}^{+∞} x dFξ(x) (интеграл Лебега-Стилтьеса). MO конечно ⟺ E{|ξ|} < +∞.

**Физический смысл:** E{ξ} — координата «центра тяжести» распределения.

**Свойства математического ожидания:**
- **С1.** E{С} = С (мат. ожид. константы равно константе);
- **С2.** E{1_A(ω)} = P(A) (мат. ожид. индикаторной функции);
- **С3 (линейность).** E{c₁ξ₁ + c₂ξ₂} = c₁E{ξ₁} + c₂E{ξ₂};
- **С4.** |E{ξ}| ≤ E{|ξ|};
- **С5.** c₁ ≤ ξ ≤ c₂ п.н. ⟹ c₁ ≤ E{ξ} ≤ c₂;
- **С6.** ξ ≤ η п.н. ⟹ E{ξ} ≤ E{η};
- **С7 (мат. ожид. от функции).** E{g(ξ)} = Σ g(aₖ) P{ξ = aₖ} или ∫g(x)pξ(x)dx.

---

### ВОПРОС 15. Неравенства для математического ожидания. Мультипликативное свойство

**С8 (неравенство Чебышёва относительно МО).** Если ξ ≥ 0 п.н., то ∀ ε > 0:
> **P{ξ ≥ ε} ≤ E{ξ} / ε.**

Следствия: P{|ξ| ≥ ε} ≤ E{|ξ|}/ε = E{ξ²}/ε²; если E{ξ} = 0, то ξ = 0 п.н.

**С9 (неравенство Йенсена).** Для выпуклой функции g:
> **E{g(ξ)} ≥ g(E{ξ}).**
> Следствие: |E{ξ}|ʳ ≤ E{|ξ|ʳ} при r ≥ 1.

**С10 (неравенство Ляпунова).** При 0 < s < t:
> **(E{|ξ|ˢ})^{1/s} ≤ (E{|ξ|ᵗ})^{1/t}.**
> Цепочка: E{|ξ|} ≤ √E{ξ²} ≤ ∛E{|ξ|³} ≤ …

**С11 (неравенство Гёльдера).** При 1/p₁ + 1/p₂ = 1, p₁, p₂ > 1:
> |E{ξ₁ · ξ₂}| ≤ E{|ξ₁ · ξ₂|} ≤ (E{|ξ₁|^{p₁}})^{1/p₁} · (E{|ξ₂|^{p₂}})^{1/p₂}.
> **Неравенство Коши-Буняковского:** |E{ξ₁ · ξ₂}| ≤ √(E{ξ₁²} · E{ξ₂²}).

**С12 (мультипликативное свойство).** Если ξ₁, ξ₂ **независимы**, то:
> **E{ξ₁ · ξ₂} = E{ξ₁} · E{ξ₂}.**

### ВОПРОС 16. Условное математическое ожидание и его свойства

**Определение 1.** **Условное МО** E{ξ | B} при P(B) > 0 вычисляется:
- Для дискретной ξ: E{ξ | B} = Σ aᵢ P{ξ = aᵢ | B};
- Для непрерывной ξ: E{ξ | B} = ∫ x pξ(x | B) dx.

**Теорема (связь условного и безусловного МО):** E{ξ} = Σ P(Hᵢ) E{ξ | Hᵢ}.

**Определение 3.** **Условное МО относительно η** — случайная величина α = E{ξ | η} = g(η(ω)), где g(y) = E{ξ | η = y}.

**Свойства условного МО:**
- **С1.** Обладает всеми свойствами безусловного МО;
- **С2.** Если ξ и η независимы: E{ξ | η = y} = E{ξ};
- **С3 (формула полного МО).** **E{ξ} = E{E{ξ | η}}** (двухэтапное усреднение);
- **С4.** E{ψ(η)·ξ | η} = ψ(η)·E{ξ | η} п.н.;
- **С5 (соотношение Вальда).** E{Sη} = E{η}·E{ξ₁} (для суммы случайного числа одинаково распределённых слагаемых).

### ВОПРОС 17. Моменты скалярной случайной величины. Дисперсия и её свойства

**Определение 1.** **Начальный момент k-го порядка:**
> νₖ = E{ξᵏ}.

**Определение 2.** Центрированная СВ: ξ° = ξ − E{ξ}.

**Определение 3.** **Центральный момент k-го порядка:**
> μₖ = E{(ξ°)ᵏ} = E{(ξ − Eξ)ᵏ}.

Свойства: ν₁ = E{ξ}, μ₁ = 0.

**Дисперсия** — центральный момент 2-го порядка:
> **D{ξ} = μ₂ = E{(ξ − E{ξ})²}.**

Среднеквадратическое отклонение: σξ = √D{ξ} ≥ 0.

**Свойства дисперсии:**
- **С1.** D{ξ} ≥ 0;
- **С2.** D{ξ} = 0 ⟺ ξ = const п.н.;
- **С3.** **D{ξ} = E{ξ²} − (E{ξ})²**;
- **С4.** D{aξ + b} = a²D{ξ} (аффинное преобразование);
- **С5.** D{ξ + η} = D{ξ} + D{η} + 2E{(ξ − Eξ)(η − Eη)};
  - Следствие: если ξ и η **независимы**, то D{ξ + η} = D{ξ} + D{η};
- **С6 (неравенство Чебышёва).** ∀ ε > 0: **P{|ξ − Eξ| ≥ ε} ≤ D{ξ} / ε²**;
  - **Правило «3σ»:** с вероятностью ≥ 8/9 СВ ξ попадает в 3σ-окрестность E{ξ}.

### ВОПРОС 18. МО и дисперсия для основных законов распределения

| Закон | Параметры | **E{ξ}** | **D{ξ}** |
|---|---|---|---|
| Бернулли Bi(1, p) | p ∈ [0, 1], q = 1−p | p | pq |
| Биномиальное Bi(N, p) | N, p | Np | Npq |
| Геометрическое G(p) | p | (1−p)/p | (1−p)/p² |
| Пуассона Π(λ) | λ > 0 | λ | λ |
| Равномерное R[a, b] | a < b | (a+b)/2 | (b−a)²/12 |
| Нормальное N(a, D) | a, D > 0 | a | D |
| Показательное E(λ) | λ > 0 | 1/λ | 1/λ² |
| Стандартное нормальное N(0,1) | — | 0 | 1 |

**Распределение Коши C(0,1):** математическое ожидание **не существует** (интеграл расходится).

### ВОПРОС 19. Ковариация, коэффициент корреляции и их свойства

**Определение 2.** **Ковариацией** СВ ξᵢ, ξⱼ называется:
> **σᵢⱼ = cov{ξᵢ, ξⱼ} = E{(ξᵢ − mᵢ)(ξⱼ − mⱼ)}.**

(n × n)-матрица **Σ = (σᵢⱼ)** — **ковариационная матрица**.

**Свойства ковариации:**
- **С1.** Удобная формула: σᵢⱼ = E{ξᵢ · ξⱼ} − E{ξᵢ} · E{ξⱼ};
- **С2.** Σ = E{(ξ − Eξ)(ξ − Eξ)ᵀ};
- **С3.** Ковариационная матрица **симметрична**: Σ = Σᵀ;
- **С4.** Диагональные элементы — дисперсии: σᵢᵢ = D{ξᵢ} ≥ 0;
- **С5.** |σᵢⱼ| ≤ √(σᵢᵢ · σⱼⱼ);
- **С6.** Ковариационная матрица **неотрицательно определена**: ∀ u ∈ Rⁿ: uᵀΣu ≥ 0;
- **С7.** Если ξᵢ и ξⱼ **независимы**, то σᵢⱼ = 0;
- **С8.** D{ξ + η} = D{ξ} + D{η} + 2cov{ξ, η}.

**Определение 3.** **Коэффициент корреляции:**
> **ρᵢⱼ = cov{ξᵢ, ξⱼ} / √(D{ξᵢ} · D{ξⱼ}) = σᵢⱼ / √(σᵢᵢ σⱼⱼ).**

**Свойства коэффициента корреляции:**
- **С1.** ρᵢⱼ = ρⱼᵢ;
- **С2.** ρᵢᵢ = 1;
- **С3.** ρᵢⱼ ∈ [−1, 1];
- **С4.** Независимые СВ **некоррелированы** (ρᵢⱼ = 0);
- Обратное **неверно**: некоррелированность ≠ независимость;
- **С5.** Для гауссовских СВ независимость ⟺ некоррелированность;
- **С6.** |ρᵢⱼ| = 1 ⟺ ξⱼ = aξᵢ + b п.н. (линейная зависимость).

**Замечание.** ρᵢⱼ есть **мера линейной зависимости**: чем больше |ρᵢⱼ|, тем сильнее зависимость.

### ВОПРОС 20. Характеристическая функция и её свойства

**Определение 1.** **Характеристической функцией** СВ ξ называется:
> **fξ(t) = E{e^{itξ}}**, t ∈ R.

По формуле Эйлера: E{e^{itξ}} = E{cos(tξ)} + iE{sin(tξ)}.

Формулы вычисления:
- Дискретная: fξ(t) = Σ e^{itaₖ} P{ξ = aₖ};
- Непрерывная: fξ(t) = ∫ e^{itx} pξ(x) dx.

**Характеристические функции основных законов:**
- Bi(1, p): fξ(t) = 1 + p(e^{it} − 1);
- Bi(N, p): fξ(t) = (1 + p(e^{it} − 1))ᴺ = (pe^{it} + 1−p)ᴺ;
- Π(λ): fξ(t) = exp{λ(e^{it} − 1)};
- N(0, 1): fξ(t) = e^{−t²/2};
- N(a, σ²): fξ(t) = exp{ita − σ²t²/2};
- E(λ): fξ(t) = (1 − it/λ)⁻¹.

**Свойства характеристической функции:**
- **С2 (ограниченность).** fξ(0) = 1 и |fξ(t)| ≤ 1 = fξ(0) ∀ t. Следствие: х.ф. существует для любой СВ.
- **С3 (комплексное сопряжение).** f̄ξ(t) = fξ(−t) = f_{−ξ}(t).
- **С4 (линейное преобразование).** f_{a+bξ}(t) = e^{ita} fξ(bt).
- **С5 (сумма независимых СВ).** fξ₁+…+ξₙ(t) = Πₖ fξₖ(t). Следствие: для одинаково распределённых fξ₁+…+ξₙ(t) = (fξ(t))ⁿ.
- **С7 (связь с моментами).** Если E{|ξ|ᵏ} < ∞, то fξ(t) дифференцируема k раз и: **νₖ = fξ^{(k)}(0) / iᵏ**.
- **С8 (теорема обращения).** ФР и х.ф. связаны: Fξ(y) − Fξ(x) = lim_{t→∞} (1/2π) ∫ (e^{−itx} − e^{−ity})/(it) fξ(t) dt.
- **С9 (теорема единственности).** Fξ(·) и fξ(·) находятся во **взаимнооднозначном** соответствии.

## ГЛАВА 4. СЛУЧАЙНЫЕ ПОСЛЕДОВАТЕЛЬНОСТИ И ИХ СХОДИМОСТЬ

### ВОПРОС 21. Случайные последовательности: сходимость по распределению, по вероятности, в среднем

**Определение 1.** **Случайная последовательность** — счётное параметрическое семейство СВ ξ₁, ξ₂, …, заданных на одном (Ω, F, P).

**Определение 2 (сходимость по распределению, D-сходимость):**
> ξₖ →^D ξ, если ∀ x ∈ C(Fξ): lim_{k→∞} Fξₖ(x) = Fξ(x).

**Определение 3 (сходимость по вероятности, P-сходимость):**
> ξₖ →^P ξ, если ∀ ε > 0: lim_{k→∞} P{|ξₖ − ξ| > ε} = 0.

**Определение 4 (сходимость в среднем порядка r, Lʳ-сходимость):**
> ξₖ →^{Lʳ} ξ, если E{|ξₖ|ʳ} < ∞, E{|ξ|ʳ} < ∞ и lim_{k→∞} E{|ξₖ − ξ|ʳ} = 0.

**При r = 2** — **сходимость в среднем квадратическом**: ξₖ →^{c.к.} ξ (l.i.m. ξₖ = ξ).

---

### ВОПРОС 22. Сходимость почти наверное. Эквивалентные определения

**Определение 6 (сходимость почти наверное):**
> ξₖ →^{п.н.} ξ, если P{ω : lim_{k→∞} ξₖ(ω) = ξ(ω)} = 1.

**Теорема (эквивалентные определения):**
> ξₖ →^{п.н.} ξ ⟺ P(∩_{k=1}^∞ ∪_{n=k}^∞ Aₙ) = 0 ⟺ ∀ε > 0: lim_{k→∞} P{sup_{n≥k} |ξₙ − ξ| > ε} = 0,
> где Aₙ = {ω : |ξₙ(ω) − ξ(ω)| > ε}.

**Следствие.** Если ∀ ε > 0 сходится ряд Σ P{|ξₙ − ξ| > ε}, то ξₙ →^{п.н.} ξ.

---

### ВОПРОС 23. Условия сходимости случайных последовательностей

**Критерий Коши (по вероятности):** последовательность сходится по вероятности ⟺ она фундаментальна по вероятности: ∀ ε > 0: lim_{m,n→∞} P{|ξₘ − ξₙ| > ε} = 0.

**Критерий Коши (в Lʳ):** ξₖ сходится в Lʳ ⟺ lim_{m,n→∞} E{|ξₘ − ξₙ|ʳ} = 0.

**Критерий Коши (п.н.):** ξₖ сходится п.н. ⟺ ∀ ε > 0: lim_{k→∞} P{sup_{m,n≥k} |ξₘ − ξₙ| > ε} = 0.

**Достаточные признаки сходимости п.н.:**
- **Теорема 1.** Если с вероятностью 1 наступает лишь конечное число событий Aₙ = {|ξₙ − ξ| > ε}, то ξₙ →^{п.н.} ξ.
- **Теорема 2.** Достаточно, чтобы сходились ряды Σ εₖ и Σ P{|ξₖ₊₁ − ξₖ| > εₖ}.

**Критерий сходимости в среднем квадратическом (Теорема 3):** ξₖ →^{c.к.} ξ ⟺ существует конечный предел lim_{m,n→∞} E{ξₘ · ξₙ} = A < ∞.

---

### ВОПРОС 24. Соотношения между видами сходимости

**Теорема 3 (схема соотношений):**

```
п.н.          Lʳ → Lq (r > q)
ξₖ → ξ                ↓
      ↓      Lq        P        D
      → ξₖ → ξ → ξₖ → ξ → ξₖ → ξ
```

Иначе: ξₖ →^{п.н.} ξ ⟹ ξₖ →^P ξ ⟹ ξₖ →^D ξ; ξₖ →^{Lʳ} ξ ⟹ ξₖ →^{Lq} ξ ⟹ ξₖ →^P ξ ⟹ ξₖ →^D ξ.

**Замечание.** Приведённая схема является **полной** — без дополнительных условий другие соотношения отсутствуют.

**Теорема 1.** Из всякой последовательности, сходящейся по вероятности, можно выделить подпоследовательность, сходящуюся **почти наверное**.

---

### ВОПРОС 25. Закон больших чисел и условия его выполнения

**Идея ЗБЧ:** среднее арифметическое случайных величин сходится по вероятности к их средним значениям.

**Теорема 1 (критерий ЗБЧ).** Последовательность ξₖ удовлетворяет ЗБЧ в форме (1/n)Σ(ξₖ − aₖ) →^P 0 тогда и только тогда, когда:
> E{((Σ(ξₖ − aₖ))² / (n + |Σ(ξₖ − aₖ)|)²)} → 0.

**Теорема 2 (условие Маркова).** Если (1/n²) D{Σᵢ₌₁ⁿ ξₖ} → 0, то ЗБЧ выполнен.

**Теорема 3 (условие Чебышёва).** Если ξₖ — попарно независимые СВ с D{ξₖ} ≤ c < ∞, то ЗБЧ выполнен.

**Теорема 4 (Бернулли).** Если ξₖ — одинаково распределённые независимые Бернулли с P{ξₖ = 1} = p, то (1/n)Σξₖ →^P p. Эквивалентная формулировка: νₙ(A) = m/n →^P p.

**Теорема 5 (условие Пуассона).** Для независимых Бернулли с различными pₖ: (1/n)Σ(ξₖ − pₖ) →^P 0.

---

### ВОПРОС 26. Усиленный закон больших чисел (УЗБЧ)

**Определение.** Последовательность ξₖ удовлетворяет **УЗБЧ**, если (1/n)Σ(ξₖ − aₖ) →^{п.н.} 0.

**Замечание.** УЗБЧ влечёт ЗБЧ; требует более жёстких условий (независимость в совокупности).

**Лемма (неравенство Гаека-Реньи).** Для независимых ξₖ, невозрастающей cₖ, ∀ ε > 0, m < n:
> P{max_{m≤k≤n} cₖ |Σⱼ(ξⱼ − aⱼ)| > ε} ≤ (1/ε²)(cₘ² Σⱼ₌₁ᵐ σⱼ² + Σⱼ₌ₘ₊₁ⁿ cⱼ² σⱼ²).

**Следствие 1 (неравенство Колмогорова):**
> P{max_{1≤k≤n} |Σⱼ₌₁ᵏ (ξⱼ − aⱼ)| > ε} ≤ (1/ε²) D{Σⱼ₌₁ⁿ ξⱼ}.

**Теорема 1 (условие Колмогорова для УЗБЧ).** Если ξₖ — независимые в совокупности и сходится **ряд Колмогорова** K = Σₖ₌₁^∞ σₖ²/k² < ∞, то ξₖ удовлетворяет УЗБЧ.

**Теорема 2 (Колмогоров, одинаково распределённые).** Для независимых одинаково распределённых ξₖ: (1/n)Σξₖ →^{п.н.} a ⟺ E{|ξ₁|} < ∞ и E{ξ₁} = a.

**Теорема 3 (Борель).** Теорема Бернулли усиленная: νₙ(A) = m/n →^{п.н.} p.

**Теорема 4 (Хинчин).** Для независимых одинаково распределённых с E{ξ₁} = a: (1/n)Σξₖ →^P a (ослабление теоремы Колмогорова).

---

### ВОПРОС 27. Центральная предельная теорема. Неравенство Берри-Эссеена. Теорема Муавра-Лапласа

**Теорема 1 (ЦПТ).** Пусть ξₖ — независимые одинаково распределённые СВ с E{ξₖ} = a и D{ξₖ} = D < ∞. Тогда:
> **P{Sₙ° < x} = P{(Sₙ − na) / √(nD) < x} → Φ(x)**, x ∈ R.

Иначе: Sₙ = Σξₖ при n → ∞ **распределена асимптотически нормально** с МО na и дисперсией nD.

**Теорема 2 (неравенство Берри-Эссеена):**
> sup_x |P{(Sₙ − na) / √(nD) < x} − Φ(x)| ≤ C · E|ξ₁ − a|³ / (√n · D^{3/2}).

**Теорема 3 (Муавра-Лапласа).** Для независимых Бернулли ξₖ с P{ξₖ = 1} = p:
> **P{(Sₙ − np) / √(np(1−p)) < x} → Φ(x).**

Приближённая формула: P{X ≤ m < Y} ≈ Φ((Y − np) / √(np(1−p))) − Φ((X − np) / √(np(1−p))).

## ГЛАВА 1. ТЕОРИЯ СТАТИСТИЧЕСКОГО ОЦЕНИВАНИЯ ПАРАМЕТРОВ

### ВОПРОС 28. Случайная выборка. Понятие статистики, статистической оценки. Состоятельность, несмещённость, точность

**Определение 1.** Множество результатов n независимых повторений эксперимента X = (x₁, …, xₙ)ᵀ ∈ R^{nN} называется **случайной выборкой объёма n** из N-мерного распределения F(·; θ). Ключевые свойства: 1) выборочные значения независимы; 2) одинаково распределены.

**Определение 2.** Произвольная борелевская функция от выборки T = T(X) : R^{nN} → Rᵏ, **не зависящая** от вида F(·; θ), называется **статистикой**.

**Определение 3.** Статистическая оценка: θ̃ = T(X) : R^{nN} → Θ ⊆ Rᵐ.

**1. Состоятельность:**
> θ̃ называется **состоятельной**, если ∀ θ⁰ ∈ Θ: θ̃ →^P θ⁰ при n → ∞.
> **Строго состоятельная** — сходимость почти наверное.

**2. Несмещённость:**
> **Смещение:** b(n, θ⁰) = E_{θ⁰}{θ̃ − θ⁰} = E_{θ⁰}{T(X)} − θ⁰.
> θ̃ **несмещённая**, если b(n, θ⁰) = 0 ∀ n, ∀ θ⁰, т.е. E_{θ⁰}{θ̃} = θ⁰.
> θ̃ **асимптотически несмещённая**, если lim_{n→∞} b(n, θ⁰) = 0.

**3. Точность:**
> **Матрица вариаций** V = (vᵢⱼ) = E_{θ⁰}{(θ̃ − θ⁰)(θ̃ − θ⁰)ᵀ}; vᵢᵢ — средний квадрат ошибки оценки i-го параметра.
> Связь с ковариационной матрицей: V = Σ + b·bᵀ. Для несмещённой: V = Σ.

---

### ВОПРОС 29. Выборочная ФР, выборочная х.ф., выборочные моменты, гистограмма

**Определение 1.** **Выборочная ФР (эмпирическая ФР):**
> **F̃ₙ(x) = (1/n) Σⱼ₌₁ⁿ 1(x − xⱼ)**, x ∈ R.

При упорядочении: F̃ₙ(x) = (кол-во xⱼ < x) / n — ступенчатая функция с прыжками 1/n.

**Определение 2.** **Выборочная х.ф.:** g̃ₙ(t) = (1/n) Σⱼ e^{itxⱼ}.

**Определение 3.** **Выборочный момент k-го порядка:** ãₖ = (1/n) Σⱼ xⱼᵏ. При k = 1: x̄ = (1/n)Σxⱼ — **выборочное среднее**.

**Выборочная дисперсия:** s̃² = ã₂ − ã₁² = (1/n) Σ(xⱼ − x̄)².
**Исправленная выборочная дисперсия:** S² = (1/(n−1)) Σ(xⱼ − x̄)².

**Теорема 1.** F̃ₙ(x), g̃ₙ(t) и ãₖ являются **строго состоятельными, несмещёнными** оценками для F(·), g(·) и αₖ соответственно:
> V{F̃(x)} = F(x)(1−F(x))/n; V{ãₖ} = (α₂ₖ − αₖ²)/n.

**Теорема 2.** F̃ₙ(x) и ãₖ при n → ∞ **распределены асимптотически нормально**.

**Гистограмма.** Разбиваем область значений на K ячеек Γₖ = [bₖ₋₁, bₖ). Частоты νₖ — кол-во выборочных значений в Γₖ.
> **f̃ₙ(x) = Σₖ νₖ / (n(bₖ − bₖ₋₁)) · 1_{Γₖ}(x)** — гистограммная оценка плотности.
> Для состоятельности нужно: K = Kₙ → ∞, max(bₖ − bₖ₋₁) → 0.

---

### ВОПРОС 30. Неравенство Крамера-Рао. Эффективные оценки

**Определение 1.** **Количество информации по Фишеру** для выборки:
> Iₙ = E_{θ}{(∂ ln f(X; θ)/∂θ)²} = D_{θ}{∂ ln f(X; θ)/∂θ} = nI,
> где I = ∫(∂ ln p(t; θ)/∂θ)² p(t; θ) dt — информация для одного наблюдения.

**Теорема (неравенство Крамера-Рао).** При условиях регулярности:
> **D_{θ}{θ̃} ≥ (g′(θ))² / Iₙ**, где g(θ) = E_{θ}{θ̃}.

Знак равенства достигается ⟺ ∂ ln f(X; θ)/∂θ = K · (T(X) − g(θ)) п.н.

Для несмещённой оценки: **D_{θ}{θ̃} ≥ 1/Iₙ = 1/(nI)**.

**Определение 2.** **Эффективность** несмещённой оценки:
> εₙ = 1 / (V{θ̃} · nI).

По неравенству Крамера-Рао: 0 < εₙ ≤ 1.

**Определение 4.** θ̃ — **эффективная оценка**, если εₙ = 1 ∀ θ, ∀ n. Если εₙ → 1 при n → ∞ — **асимптотически эффективная**.

**Следствие 2 (критерий эффективности).** Несмещённая θ̃ эффективна ⟺ ∂ ln f(X; θ)/∂θ = K · (T(X) − θ) п.н., при этом K = Iₙ = nI.

---

### ВОПРОС 31. Метод моментов. Оценки по методу моментов

**Метод моментов** предложен К. Пирсоном в 1900 г.

**Принцип.** Пусть αₖ = αₖ(θ₁, …, θₘ) = E{x₁ᵏ} — теоретические моменты. Система: αₖ(θ₁, …, θₘ) = ãₖ, k = 1, …, m.

**Принцип метода моментов:** в качестве оценки θ⁰ берётся вектор θ̃, являющийся решением системы:
> **{α₁(θ₁,…,θₘ) = ã₁; … ; αₘ(θ₁,…,θₘ) = ãₘ}**,
> где ãₖ = (1/n) Σxⱼᵏ — выборочные моменты.

**Пример (нормальный закон N(a, D)):**
> Система: a = x̄; D + a² = (1/n) Σxⱼ².
> Оценки: ã = x̄, D̃ = (1/n)Σ(xⱼ − x̄)².

Так как ãₖ →^{п.н.} αₖ, то оценки по ММ, как правило, **состоятельные**.

---

### ВОПРОС 32. Метод максимального правдоподобия и его свойства

**Метод максимального правдоподобия** предложен Р. Фишером в 1930 г.

**Определение 1.** **Функция правдоподобия:** L(θ) = f(X; θ) = Πₖ₌₁ⁿ p(xₖ; θ) ≥ 0.

**Определение 2.** **Логарифмическая функция правдоподобия:** l(θ) = ln L(θ) = Σₖ ln p(xₖ; θ).

**Принцип максимума правдоподобия.** В качестве оценки берётся θ̃ = arg max_{θ} L(θ) = arg max_{θ} l(θ).

**Уравнение правдоподобия** (при дифференцируемости l):
> **∂l(θ)/∂θⱼ = 0, j = 1, …, m.**

**Свойства МП-оценки:**
- **С1 (инвариантность).** Если θ̃ — единственная МП-оценка (θ₁,…,θₘ), а τ = τ(θ) — взаимнооднозначное преобразование, то τ̃ = τ(θ̃).
- **С2 (связь с эффективной оценкой).** Если существует эффективная оценка θ̃*, то МП-оценка совпадает с ней.
- **С3 (асимптотические свойства).** При выполнении условий регулярности МП-оценка θ̃ₙ*:
  - состоятельная: θ̃ₙ* →^P θ⁰;
  - асимптотически несмещённая: E{θ̃ₙ* − θ⁰} → 0;
  - **асимптотически нормально распределённая:** P{√(nI)(θ̃ₙ* − θ⁰) < x} → Φ(x);
  - **асимптотически эффективная:** εₙ → 1.

### ВОПРОС 33. Регрессионные модели. Принцип МНК и его геометрический смысл

**Регрессионная модель наблюдений:**
> **η = f(x; θ⁰) + ε**, где f(x; θ⁰) — функция регрессии; E{ε} = 0; Σ = cov{ε, ε}.

Классификация: многомерная (N > 1), множественная (N = 1, M > 1), простая (N = M = 1); линейная/нелинейная по θ.

**Принцип МНК.** Для модели yᵢ = f(xᵢ; θ⁰) + εᵢ при L{εᵢ} = N(0, σ²):
> **θ̃ = arg min_{θ} R²(θ)**, где **R²(θ) = Σᵢ₌₁ⁿ (yᵢ − f(xᵢ; θ))²** — сумма квадратов невязок.

Yᵢ − f(xᵢ; θ) — **невязка (остаток)** в i-м эксперименте.

**Геометрический смысл МНК:** в семействе поверхностей {y = f(x; θ)} нужно найти поверхность, для которой сумма квадратов отклонений экспериментальных точек {yᵢ} минимальна.

**Линейная регрессионная модель:** Y = Xθ⁰ + E, где X — план эксперимента (n×m-матрица), E{E} = Oₙ, E{EEᵀ} = σ²Eₙ.

---

### ВОПРОС 34. Оптимальные свойства МНК-оценки для линейной регрессионной модели

**Теорема 1.** При det(XᵀX) ≠ 0 МНК-оценка **единственна**:
> **θ̃ = (XᵀX)⁻¹Xᵀ Y = C₀Y**.

МНК-оценка **несмещённая** и имеет матрицу вариаций:
> **V = σ²(XᵀX)⁻¹.**

**Следствие.** При условии Эйкена (λ_min(XᵀX) → ∞) МНК-оценка **состоятельная**.

**Теорема 2.** При n > m несмещённая оценка σ²:
> **σ̃² = (1/(n−m)) (Y − Xθ̃)ᵀ(Y − Xθ̃).**

**Теорема 3 (Гаусса-Маркова).** Среди всех **линейных несмещённых** оценок θ⁰ МНК-оценка имеет **наименьшие вариации** (BLUE — Best Linear Unbiased Estimator).

**Пример — прямая линейная регрессия** y = θ̃₁ + θ̃₂x:
> θ̃₂ = (x̄y − x̄·ȳ) / (x̄² − (x̄)²) = ΣᵢΔxᵢyᵢ / ΣᵢΔxᵢ²; θ̃₁ = ȳ − θ̃₂ x̄.

---

### ВОПРОС 35. Интервальное оценивание параметров. Методы построения доверительных интервалов

**Определение 1.** Случайный интервал (θ̲, θ̄) называется **доверительным интервалом (ДИ)** для θ с **доверительной вероятностью 1 − ε**:
> ∀ θ ∈ R: P_{θ}{θ̲ < θ < θ̄} = 1 − ε.

Типы ДИ: левосторонний (θ, +∞), правосторонний (−∞, θ̄), центральный (θ̲, θ̄) при ε₁ = ε₂ = ε/2.

Стандартные уровни: 1 − ε ∈ {0,80; 0,85; 0,90; 0,95; 0,99; …}.

**Метод 1. Метод обратной функции:**
1. Строим состоятельную оценку θ̃ = T(X);
2. Находим ФР оценки F(·; θ);
3. Решаем уравнения: F(θ̲; θ) = 1 − ε/2; F(θ̄; θ) = ε/2;
4. Находим θ̲ и θ̄.

**Пример 1 (ЦДИ для среднего при известной дисперсии).** X ~ N(θ, σ²), σ² известна:
> θ̃ = x̄; θ̲ = x̄ − φ_{1−ε/2} · σ/√n; θ̄ = x̄ + φ_{1−ε/2} · σ/√n, где φ_{0,95} ≈ 1,65.

**Пример 2 (ЦДИ для среднего при неизвестной дисперсии).** Используется t-распределение Стьюдента с n−1 ст. св.:
> θ̲ = x̄ − t_{n−1, 1−ε/2} · S/√n; θ̄ = x̄ + t_{n−1, 1−ε/2} · S/√n.

**Пример 3 (ЦДИ для дисперсии).** Используется χ²-распределение с n−1 ст.св.:
> θ̲ = S²(n−1) / h_{n−1, 1−ε/2}; θ̄ = S²(n−1) / h_{n−1, ε/2}.

**Метод 2. Асимптотический.** МП-оценки и МНК-оценки асимптотически нормальны. При большом n:
> θ̲ = θ̃ − φ_{1−ε/2} · σ̃_{θ̃}(θ̃); θ̄ = θ̃ + φ_{1−ε/2} · σ̃_{θ̃}(θ̃).

## ГЛАВА 2. ТЕОРИЯ СТАТИСТИЧЕСКОЙ ПРОВЕРКИ ГИПОТЕЗ

---

### ВОПРОС 36. Основные понятия теории статистической проверки гипотез

**Определение 1.** **Статистическая гипотеза** — любое предположение о виде теоретической ФР F(x).

H₀ — **основная** гипотеза; H₁ — **конкурирующая (альтернативная)** гипотеза.

**Определение 3.** **Статистический критерий** — правило принятия H₀ или H₁ по выборке X. Характеризуется:
- **допустимой областью Wₐ** — принятие H₀;
- **критической областью Wₖ = R^{nN} \ Wₐ** — принятие H₁.

**Определение 4.** **Ошибка первого рода** — принятие H₁ при истинной H₀. **Уровень значимости:**
> α = P{(x₁,…,xₙ) ∈ Wₖ | H₀}.

**Определение 5.** **Ошибка второго рода** — принятие H₀ при истинной H₁. **Оперативная характеристика:** β′ = P{H₀ | H₁}. **Мощность критерия:** β = 1 − β′.

**Определение 6.** **Размер критерия:** α₀ = sup_{F(x)∈F₀} α(F(x)).

**Определение 7.** **Равномерно наиболее мощный критерий (РНМК)** размера α₀ — критерий с наибольшей мощностью среди всех критериев размера α₀.

Критическое значение C находится как квантиль уровня 1 − α₀ соответствующего распределения статистики.

---

### ВОПРОС 37. Критерий отношения правдоподобия. Последовательный КОП

**Для простых гипотез** H₀: F(x) = F₀(x); H₁: F(x) = F₁(x).

**Определение.** **Отношение правдоподобия:**
> Λ = Λ(x₁,…,xₙ) = L₁(x₁,…,xₙ) / L₀(x₁,…,xₙ).

Критическая область КОП: Wₖ = {Λ(x₁,…,xₙ) > C}.

**Теорема 1 (лемма Неймана-Пирсона).** Среди всех критериев заданного уровня значимости α, проверяющих две простые гипотезы, **КОП является РНМК**.

**Последовательный КОП (ПКОП).**
1. Задаются c₀ < c₁.
2. Последовательно проводятся испытания, вычисляется λ = ln Λ.
3. Если λ ≥ c₁ — принимаем H₁; если λ ≤ c₀ — принимаем H₀; иначе — продолжаем.

Приближённые формулы: c₁ ≈ ln((1−β)/α); c₀ ≈ ln(β/(1−α)).

**Теорема 2 (Вальда).** ПКОП **минимизирует** средние числа наблюдений N₀ и N₁ среди всех критериев с теми же α, β.

---

### ВОПРОС 38. Критерии согласия

**Задача.** Проверить H₀: F(x) = F₀(x) против H₁: F(x) ≠ F₀(x).

#### Критерий Колмогорова

Мера расхождения: ρₙ = √n · sup_x |Fₙ(x) − F₀(x)|.

Принимаем H₀ при ρ < C; принимаем H₁ при ρ ≥ C. При n → ∞ распределение ρ → распределению Колмогорова. Критическое значение: C ≈ k_{1−α}.

Практическая формула:
> ρ = √n · max_{1≤i≤n} |F₀(x_{(i)}) − (2i−1)/(2n)| + 1/(2n).

#### Критерий χ² (Пирсона)

Дискретный случай. Разбиваем значения на L групп с гипотетическими вероятностями P₁,…,Pₗ. νᵢ — наблюдённые частоты.

> **χ² = Σᵢ₌₁ᴸ (νᵢ − nPᵢ)² / (nPᵢ).**

При n → ∞ имеет асимптотически χ²-распределение с L−1 ст. св. Принимаем H₀ при χ² < C = h_{L−1, 1−α}. Требование: νᵢ ≥ 5.

Для непрерывного случая: разбивают числовую прямую на L интервалов, вычисляют Pₗ = F₀(dₗ) − F₀(dₗ₋₁).

## ГЛАВА 1. СТАЦИОНАРНЫЕ СЛУЧАЙНЫЕ ПРОЦЕССЫ

### ВОПРОС 39. Случайные процессы и их вероятностные характеристики. Классификация

**Определение 1.** **Случайной функцией** ξₜ = ξ(ω, t) : Ω × T → Rᴺ называется параметрическое семейство СВ {ξₜ, t ∈ T}, заданных на одном (Ω, F, P).

Множество значений X ⊆ Rᴺ — **фазовое пространство**.

**Определение 2.** При фиксированном ω′ функция x(t) = ξ(ω′, t) — **реализация (траектория)** случайного процесса.

**Определение 3.** При фиксированном t′ СВ ξ_{t′} = ξ(ω, t′) — **отсчёт (сечение)** в точке t′.

**Классификация:**
- M = 1, T дискретно — **случайная последовательность (временной ряд)**;
- M = 1, T непрерывно — **случайный процесс с непрерывным временем**;
- M > 1 — **случайное поле**;
- X дискретно — дискретный ФП, X непрерывно — непрерывный.

**Вероятностные характеристики:**

**Определение 9.** **Математическое ожидание:** mξ(t) = E{ξₜ} = ∫ x dFξ(x, t).

**Определение 10.** **Дисперсия:** σξ²(t) = D{ξₜ} = E{(ξₜ − mξ(t))²}.

**Определение 11.** **Ковариационная функция:**
> Rξ(t₁, t₂) = E{ξ_{t₁} · ξ_{t₂}}.

**Определение 12.** **Корреляционная (автокорреляционная) функция:**
> R°ξ(t₁, t₂) = E{(ξ_{t₁} − mξ(t₁))(ξ_{t₂} − mξ(t₂))}.

Связь: R°ξ(t₁, t₂) = Rξ(t₁, t₂) − mξ(t₁)·mξ(t₂).

---

### ВОПРОС 40. Понятия стационарности случайного процесса

**Определение 1.** Случайный процесс ξₜ называется **стационарным в узком смысле**, если все его конечные функции распределения инвариантны относительно сдвига: Fξ(x₁,…,xₙ; t₁+τ,…,tₙ+τ) = Fξ(x₁,…,xₙ; t₁,…,tₙ) ∀ τ.

**Следствия:** одномерная ФР не зависит от t; двумерная ФР зависит только от t₂ − t₁.

**Определение 3.** Процесс 2-го порядка ξₜ называется **стационарным в широком смысле**, если:
- а) E{ξₜ} = mξ = const;
- б) E{ξ_{t₁} · ξ_{t₂}} = Rξ(t₂ − t₁) (зависит только от разности).

**Теорема 2.** Стационарный в узком смысле СП 2-го порядка стационарен в широком смысле.

**Для гауссовского процесса** понятия стационарности в широком и узком смысле **совпадают**.

---

### ВОПРОС 41. Свойства ковариационных функций. Непрерывность, дифференцируемость, интегрируемость в с.к.

**Свойства корреляционной функции:**
- **С1 (симметрия).** Rξ(t₁, t₂) = Rξ(t₂, t₁). Для стационарного: Rξ(τ) = Rξ(−τ) — чётная.
- **С2 (ограниченность).** |Rξ(t₁, t₂)| ≤ √(Rξ(t₁,t₁)·Rξ(t₂,t₂)). Для стационарного: |Rξ(τ)| ≤ Rξ(0).
- **С3 (неотрицательная определённость).** Q(x₁,…,xₙ) = ΣΣxᵢxⱼRξ(tᵢ,tⱼ) ≥ 0.
- **С4.** При τ → ∞: lim Rξ(τ) = mξ²; σξ² = Rξ(0) − Rξ(+∞).

**Время корреляции:**
> τ₀ = (1/R°ξ(0)) ∫₀^∞ |R°ξ(τ)| dτ.

При τ > τ₀ считается, что ξₜ и ξ_{t+τ} практически некоррелированы.

**Критерии (среднеквадратические):**

| Характеристика | Определение | Критерий |
|---|---|---|
| **с.к.-непрерывность** | ξ_{t+τ} →^{с.к.} ξₜ при τ → 0 | Rξ(t₁, t₂) непрерывна в точке (t, t) |
| **с.к.-дифференцируемость** | (ξ_{t+τ} − ξₜ)/τ →^{с.к.} ξ′ₜ | ∂²Rξ(t₁,t₂)/∂t₁∂t₂ < ∞ при t₁ = t₂ = t |
| **с.к.-интегрируемость** | ∫ξ(ω,t)f(t)dt существует в с.к. | ∫∫f(t₁)f(t₂)Rξ(t₁,t₂)dt₁dt₂ < ∞ |

Для стационарного с.к.-дифференцируемого: Rξ′(τ) = −R″ξ(τ).

---

### ВОПРОС 42. Спектральная плотность случайного процесса. Белый шум

**Определение 1.** **Спектральная плотность** — преобразование Фурье корреляционной функции:
> **Sξ(λ) = (1/2π) ∫_{−∞}^{+∞} R°ξ(τ) e^{−iλτ} dτ** = (1/2π) ∫ R°ξ(τ) cos(λτ) dτ.

**Свойства:**
- **С2.** Sξ(λ) — действительная функция;
- **С3.** Sξ(λ) — чётная: Sξ(−λ) = Sξ(λ);
- **С4.** Sξ(λ) ≥ 0;
- **С5 (формула Винера-Хинчина).** Обратное преобразование: R°ξ(τ) = ∫Sξ(λ)e^{iλτ}dλ = ∫Sξ(λ)cos(λτ)dλ;
- D{ξₜ} = R°ξ(0) = ∫Sξ(λ)dλ (дисперсия = площадь под Sξ).

**Белый шум.** Стационарный процесс νₜ называется **белым шумом** с интенсивностью c, если Sₙ(λ) = c = const.

**Свойства белого шума:**
- **С1.** R°ₙ(τ) = 2πc·δ(τ), где δ(·) — дельта-функция Дирака;
- **С3.** Отсчёты белого шума **некоррелированы** (при τ ≠ 0 R°ₙ(τ) = 0);
- **С4.** Дисперсия белого шума **бесконечна**: D{νₜ} = R°ₙ(0) = 2πc·δ(0) = ∞.

## ГЛАВА 2. МАРКОВСКИЕ СЛУЧАЙНЫЕ ПРОЦЕССЫ

---

### ВОПРОС 43. Определение и классификация марковских случайных процессов

**Определение 2.** Случайный процесс ξₜ обладает **марковским свойством** и называется **марковским**, если условная ФР будущего состояния не зависит от прошлых состояний:
> F(y, τ | x, t; xₙ, tₙ, …, x₁, t₁) = **F(y, τ | x, t)**.

F(y, τ | x, t) — **условная ФР переходов**.

**Теорема 1 (уравнение Колмогорова-Чепмена):**
> ∫_{−∞}^{+∞} F(y, τ | z, s) d_z F(z, s | x, t) = F(y, τ | x, t), t < s < τ.

**Теорема 2.** n-мерная плотность марковского процесса:
> pξ(x₁,…,xₙ; t₁,…,tₙ) = f₀(x₁,t₁) · Πᵢ₌₁^{n−1} f(xᵢ₊₁, tᵢ₊₁ | xᵢ, tᵢ).

**Классификация:**

| | T дискретно | T непрерывно |
|---|---|---|
| **X дискретно** | Цепь Маркова с дискретным временем | Цепь Маркова с непрерывным временем |
| **X непрерывно** | Марковская случайная последовательность | Марковский случайный процесс |

---

### ВОПРОС 44. Цепь Маркова с дискретным временем. Асимптотические свойства однородной ЦМДВ

**Цепь Маркова с дискретным временем (ЦМДВ):** X = {1,…,N}, T = {0,1,2,…}.

- pᵢ(0) = P{ξ₀ = i} — начальные вероятности;
- pᵢⱼ(t) = P{ξₜ₊₁ = j | ξₜ = i} — вероятность одношагового перехода i → j;
- P(t) = (pᵢⱼ(t)) — матрица переходов.
- **Однородная ЦМДВ:** P(t) = P = const.

**Теорема 1 (конечномерное распределение ЦМДВ):**
> Qₙ₊₁(x₀,…,xₙ) = p_{x₀}(0) · Πₜ₌₀^{n−1} p_{xₜ, xₜ₊₁}(t).

**Теорема 2 (формула Маркова):** P^{(s+n)} = P^{(s)} P^{(n)}.

**Следствие 1:** P^{(n)} = Pⁿ.

**Следствие 2 (распределение через n шагов):** p(n) = (Pⁿ)ᵀ p(0).

**Условие нормировки:** Σᵢpᵢ(0) = 1; Σⱼpᵢⱼ = 1 ∀ i.

#### Асимптотические свойства однородной ЦМДВ

**Определение 1.** **Стационарное распределение** p*: a) pᵢ* ≥ 0; б) Σpᵢ* = 1; в) Pᵀp* = p* (p* — собственный вектор Pᵀ).

**Теорема 1.** Если начальное распределение совпадает со стационарным p(0) = p*, то p(n) = p* ∀ n.

**Теорема 2 (эргодическая теорема).** Если существует t₀ такое, что все элементы матрицы P^{t₀} положительны, то:
> **lim_{n→∞} pᵢⱼ^{(n)} = pⱼ***, т.е. lim p(n) = p*.

**Замечание.** После достаточно большого числа шагов вероятность перехода не зависит от начального состояния.

---

### ВОПРОС 45. Цепь Маркова с непрерывным временем

**ЦМНВ:** X = {1,…,N}, T = [0, ∞).

**Определение 1.** pᵢⱼ(s, t) = P{ξₜ = j | ξₛ = i}, 0 ≤ s ≤ t — вероятность перехода.

**Определение 4.** **Интенсивность перехода:** λᵢⱼ(t) = lim_{h→0} pᵢⱼ(t, t+h) / h.

**Уравнение Колмогорова-Чепмена:** pᵢⱼ(s,t) = Σₖ pᵢₖ(s,u) pₖⱼ(u,t).

**Теорема 2 (система уравнений Колмогорова):**
> **dpᵢ(t)/dt = Σⱼ≠ᵢ λⱼᵢ pⱼ(t) − pᵢ(t) Σⱼ≠ᵢ λᵢⱼ**, i = 1, …, N.

Правило составления: производная вероятности состояния = входящие потоки − исходящие потоки.

Для нахождения **финальных (стационарных) вероятностей** dpᵢ/dt = 0, + нормировочное условие Σpᵢ = 1.

---

### ВОПРОС 46. Случайный процесс с независимыми приращениями. Винеровский процесс

**Определение 1.** Процесс ξₜ называется **процессом с независимыми приращениями**, если начальное значение и все последовательные приращения η₁ = ξ_{t₁} − ξ_{t₀}, η₂ = ξ_{t₂} − ξ_{t₁}, … **независимы в совокупности**.

**Определение 2.** Процесс Wₜ называется **винеровским** (броуновским движением), если:
- **С1.** W₀ = 0 п.н.;
- **С2.** Wₜ — процесс с независимыми стационарными приращениями;
- **С3.** L{Wₜ₂ − Wₜ₁} = N(0, b(t₂−t₁)), b > 0;
- **С4.** Wₜ непрерывен п.н.

Стандартный винеровский процесс: b = 1.

**Свойства стандартного Wₜ:**
- **С5.** L{Wₜ} = N(0, t); E{Wₜ} = 0; D{Wₜ} = t;
- **С6.** cov{W_{t₂} − W_{t₁}, W_{t₄} − W_{t₃}} = μ([t₁,t₂] ∩ [t₃,t₄]);
- **С7.** Ковариационная функция: **R_W(t₁,t₂) = min{t₁,t₂}**;
- **С8.** Wₜ **нестационарный, непрерывный, но не дифференцируемый** в с.к.

---

### ВОПРОС 47. Пуассоновский случайный процесс и его свойства

**Определение 1.** Процесс ξₜ называется **пуассоновским** с интенсивностью λ > 0, если:
- **С1.** ξ₀ = 0 п.н.;
- **С2.** Дискретное ФП X = {0,1,2,…}, независимые приращения;
- **С3.** Стационарные приращения: L{ξ_{t₂} − ξ_{t₁}} = L{ξ_{t₂−t₁}};
- **С4.** При Δt → 0: P{ξ_{t+Δt} − ξₜ = 0} = 1 − λΔt + o(Δt); P{= 1} = λΔt + o(Δt); P{≥ 2} = o(Δt).

**Теорема 1.** Одномерное распределение пуассоновского процесса:
> **P{ξₜ = k} = (λt)ᵏ e^{−λt} / k!** (распределение Пуассона с параметром λt).

**Теорема 2.** Промежутки времени τᵢ между соседними скачками — **независимые одинаково распределённые** СВ: **L{τᵢ} = E(λ)** (показательный закон с параметром λ).

**Пример (радиоактивный распад).** Время полураспада t₀ = ln2/λ.

## ГЛАВА 3. СТАТИСТИЧЕСКИЙ АНАЛИЗ ВРЕМЕННЫХ РЯДОВ

---

### ВОПРОС 48. Понятие временного ряда. Оценка математического ожидания и её свойства

**Определение.** **Временной ряд** — последовательность наблюдений, упорядоченная во времени: X = (x₁, …, xₜ), где xₜ ∈ R.

Математическая модель {xₜ} — стационарный процесс с дискретным временем:
> m = E{xₜ} = const; γ(τ) = R°ₓ(t, t+τ) = E{(x_{t+τ} − m)(xₜ − m)}.

**Оценка МО:**
> **x̄ = (1/T) Σᵢ₌₁ᵀ xᵢ.**

**Свойства:**
- **С1. Несмещённость:** E{x̄} = m;
- **С2. Дисперсия оценки:**
  > D{x̄} = (1/T) Σ_{τ=−(T−1)}^{T−1} (1 − |τ|/T) γ(τ);
- **Состоятельность:** если γ(τ) = 0 ∀τ ≠ 0 (независимые наблюдения), то D{x̄} = γ(0)/T → 0;
- Состоятельность при более слабом условии: D{x̄} → 0 при T → ∞.

---

### ВОПРОС 49. Оценка корреляционной функции. Оценивание тренда МНК

**Оценка корреляционной функции:**
> **γ̃(τ) = (1/(T−τ)) Σᵢ₌₁^{T−τ} (xᵢ − x̄)(xᵢ₊τ − x̄)**, τ = 0, 1, 2, …

При τ = 0: γ̃(0) = (1/T) Σ(xᵢ − x̄)² (выборочная дисперсия по принципу T).

**Модель временного ряда с трендом:**
> xₜ = g(t) + uₜ, где uₜ — некоррелированные СВ с E{uₜ} = 0, D{uₜ} = σ², g(t) — тренд.

**Оценивание тренда МНК** для полиномиального тренда g(t) = Σᵢ₌₁ᵐ aᵢtⁱ:
> Σₜ₌₁ᵀ (xₜ − Σᵢ aᵢtⁱ)² → min, что приводит к нормальным уравнениям:
> Σᵢ (Σₜ t^{i+j}) aᵢ = Σₜ xₜtʲ, j = 1, …, m.

Оценки ãᵢ — асимптотически несмещённые и состоятельные; тренд g̃(t) = Σãᵢtⁱ также асимптотически несмещённый и состоятельный.
